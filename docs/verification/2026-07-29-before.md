- The dashboard already leads with the Today session card (daily-loop Task 4).
- The learner-facing companion is still Lumi — a childlike cartoon figure — on

- `/today` rendered an endless splash for a learner with no bound account,
  because session composition returns null without a `profileId`. Fixed in

- The store has no learner-avatar preview and no "no real money" statement.
