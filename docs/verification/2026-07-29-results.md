## Defects found and fixed during verification

1. **`/today` hung on an endless splash** whenever session composition returned
   null (which it does when `settings.profileId` is unset). Now renders an
   explanatory retry card. Commit `9de98d9`.
2. **Technical recognition errors rendered as learner misses** in the shadowing
   round — a network drop showed the same red phrase and "Try again" miss badge
   as a real mistake. Now a neutral notice; nothing scored. Commit `2a7cac6`.
3. **Post-midnight returns could credit the wrong session**, because activity
   ids repeat across days. Returns now carry `sessionDay` and stale days are
   rejected. Commit `2a7cac6`.
4. **Checkpoint blocked on a cloud pull** before the durable local write. Now
   writes locally first. Commit `2a7cac6`.
5. **Cap artwork placement**: a single per-base anchor put brims over the
   learner's eyes on half the catalog and clipped two caps off-canvas. Replaced
   with per-cap head-opening metadata measured from sprite alpha, verified
   across all 12 pairs.

## Coverage limits — recorded as unverified, not as passes

- Safari and Firefox: not run. Chromium only.
- Physical iPhone: microphone capture, Safari PWA install, OAuth redirect, and
  push notification delivery are all owner-assisted.
- Authenticated production smoke tests need an owner account on the allowlist.
- Speech-recognition failure and denied-microphone are covered by unit tests and
  by the recovery UI, but not by a browser permission simulation.
- The Supabase merge RPC is tested by an executable logic fixture and reviewed
  by hand; it has not been executed against a real PostgreSQL runtime.
