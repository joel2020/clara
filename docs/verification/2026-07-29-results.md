## Defects found and fixed during verification

1. **`/today` hung on an endless splash** whenever session composition returned
   null (which it does when `settings.profileId` is unset). Now renders an
   explanatory retry card. Commit `9de98d9`.
2. **Technical recognition errors rendered as learner misses** in the shadowing
   round — a network drop showed the same red phrase and "Try again" miss badge
   as a real mistake. Now a neutral notice; nothing scored. Commit `2a7cac6`.
3. **Post-midnight returns could credit the wrong session**, because activity
   ids repeat across days. Returns now carry `sessionDay` and stale days are
   rejected. Commit `2a7cac6`.
4. **Checkpoint blocked on a cloud pull** before the durable local write. Now
   writes locally first. Commit `2a7cac6`.
5. **Cap artwork placement**: a single per-base anchor put brims over the
   learner's eyes on half the catalog and clipped two caps off-canvas. Replaced
   with per-cap head-opening metadata measured from sprite alpha, verified
   across all 12 pairs.

## Remaining educational risks

1. **No evidence of measured learning yet.** Every metric here is behavioral
   (completion, participation, return). Nothing in this release demonstrates
   that pronunciation actually improves; the pilot is the first real test.
2. **The composer's ranking is unvalidated pedagogy.** Due-first, then path,
   weakness, recency, fatigue is a reasonable ordering, but no evidence says it
   beats the previous learner-chosen order for retention.
3. **The 15-minute cap is a product judgment**, not a finding about attention or
   spacing for adult learners.
4. **Improvement is never asserted** because it cannot yet be derived from
   session evidence. Honest, but it means the learner gets no positive signal
   that a specific sound got better.
5. **Placement can be skipped**, so a learner may run at the wrong level for
   days before the composer's evidence catches up.
6. **Speech scoring quality is unchanged** by this release and remains the
   weakest link in any claim about spoken accuracy.
7. **Humor is untested with real learners.** The safety rules are enforced by
   tests; whether the lines land is unknown.
